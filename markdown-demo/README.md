# 📝 Introductie tot Markdown

> Een beginnersvriendelijke introductie tot Markdown: de eenvoudige opmaaktaal die je tekst omzet naar nette, leesbare documenten.

---

## 📖 Over dit materiaal

Deze presentatie is bedoeld als kennismaking met Markdown voor studenten en beginners. Na het doorlopen van dit materiaal kun je:

- begrijpen wat Markdown is en waarom het nuttig is,
- basisopmaak toepassen zoals koppen, lijsten en vetgedrukte tekst,
- links en afbeeldingen invoegen,
- codeblokken gebruiken voor technische inhoud,
- Markdown gebruiken in tools zoals GitHub, Notion en VS Code.

## 🚀 Aan de slag

Je hebt geen speciale software nodig om Markdown te lezen of te schrijven. Een gewone teksteditor volstaat. Wil je een livevoorbeeld zien terwijl je typt? Gebruik dan een van de volgende tools:

- **[VS Code](https://code.visualstudio.com/)** met de ingebouwde Markdown-preview (`Ctrl+Shift+V`)
- **[StackEdit](https://stackedit.io/)** - een online editor in de browser
- **[Dillinger](https://dillinger.io/)** - een andere online optie
- **GitHub** - toont `.md`-bestanden automatisch opgemaakt
