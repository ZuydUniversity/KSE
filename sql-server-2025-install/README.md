# Installatiehandleiding Microsoft SQL Server 2025 (Windows 11 Desktop)

## 1. Edities
- Enterprise
- Standard
- Express (Om te leren is deze ideaal om te gebruiken, je kunt altijd upgraden naar een rijkere editie als je features mist)
- Standard Developer editie (Deze kun je ook gebruiken om te developen, maar is alleen gelicientieerd als een ontwikkel- en testsysteem)

Voor meer gedetailleerde informatie verwijzen we naar [SQL Server Editions](https://learn.microsoft.com/en-us/sql/sql-server/editions-and-components-of-sql-server-2025?view=sql-server-ver17)

## 2. Systeemeisen
- Operating systeem: Windows 11 met laatste updates
- Storage: minimaal 6 GB
- Process: 64-bits processor, met aanbevolen snelheid van 2.0Ghz of sneller

Voor meer gedetailleerde informatie verwijzen we naar [Hardware and Software Requirements](https://learn.microsoft.com/en-us/sql/sql-server/install/hardware-and-software-requirements-for-installing-sql-server-2025?view=sql-server-ver17)

## 3. Download
- Op [deze](https://www.microsoft.com/nl-nl/sql-server/sql-server-downloads) pagina kun je de installers downloaden van zowel de SQL Server 2025 developer of de SQL Server 2025 Express.

## 4. Start installer
- Rechtermuis knop op SQL2025-SSEI-Expr.exe en "run as administrator"
